# Zipp: Africa's Mobility Reimagined

Here's a prompt designed specifically for Lovable to generate a polished, startup-quality landing page. It is written as if you're briefing a senior product designer and frontend engineer at a company like Stripe, Linear, or Airbnb.

Prompt for Lovable

Build a modern, premium, production-ready landing page for Zipp, an African ride-hailing platform that is reimagining transportation across Africa.

The design should feel like a cross between Uber, Stripe, Linear, Apple, and Notion—minimal, premium, elegant, and trustworthy. It should not feel like a generic template. It should look like a startup that just raised a Series A.
